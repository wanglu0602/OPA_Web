项目说明

介绍当前网站的技术结构、页面关系、使用方式以及后续扩展方向。

1. 网站结构

index.html      — 首页
project.html    — 项目介绍
research.html   — 原理与方法
simulation.html — 在线仿真（保持原有仿真页面代码不变）
data.html       — 数据与指标
about.html      — 项目说明
assets/style.css — 其它页面的统一样式

2. 在线仿真页面为什么保持不变

你的仿真页已经完成了核心交互和算法展示，因此本网站采用“外部科研展示页面 + 原仿真页面”的结构，而不是继续修改仿真页面本身。

这意味着以后你如果继续改仿真，只需要替换 simulation.html，而首页、项目介绍、原理、数据指标和项目说明页面不需要一起重写。

3. 技术栈

HTML5 CSS3 JavaScript Three.js Raycaster Canvas GitHub Pages

4. 当前边界

当前是浏览器实时模型

为了保证网页流畅，FMCW 部分使用实时近似模型和频率估计扰动，而不是对每条射线都执行高成本长序列完整 FFT。

当前三维场景是简化几何

目标使用 Three.js 基本几何体构建。后续可以加入 STL、OBJ、glTF 等真实模型和复杂三角网格。

5. 后续可扩展方向

真实 I/Q 与 FFT

加入完整采样序列、窗函数、FFT、峰值插值和多目标谱峰检测。

Python 后端

使用 FastAPI 执行高计算量算法、保存实验数据和管理不同仿真任务。

复杂目标模型

支持真实车辆、道路、建筑以及用户上传的三维场景。

实验记录

自动保存参数、σ、命中率、FPS 和 CSV 数据，形成可复现实验记录。

结果页面

生成论文风格曲线，如 SNR-σ、带宽-σ、扫描模式-命中率等。

论文/答辩展示

加入摘要、论文 PDF、视频演示、实验结论和项目联系方式。

6. GitHub Pages 更新方式

  1. 首页等科研页面发生变化：重新上传对应 HTML/CSS 文件。
  2. 仿真代码发生变化：只替换 simulation.html。
  3. 保持所有文件位于仓库根目录，assets 文件夹与 HTML 页面同级。
  4. GitHub Pages 会在提交后自动重新部署。
